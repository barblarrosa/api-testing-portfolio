# API Testing Portfolio — Postman

An API testing portfolio built with Postman and Newman, including
full QA documentation: test plan, test cases, bug reports, and a
requirements traceability matrix.

## Status
In progress — started September 2026.

## Stack
- Postman
- Newman (CLI execution and HTML reports)
- JavaScript (scripting and assertions)

## System Under Test

## Repository Structure
- `collections/` — exported Postman collections
- `environments/` — environment files (no credentials)
- `data/` — CSV and JSON files for data-driven testing
- `docs/` — test plan, test cases, bug reports, traceability matrix
- `reports/` — execution reports
